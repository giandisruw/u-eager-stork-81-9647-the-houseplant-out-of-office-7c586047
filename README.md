A make.fun entry for **The Houseplant Out-of-Office**: the funniest
out-of-office auto-reply a houseplant would send, in 120 characters or fewer.

## The entry

> Hi, I'm out — the cactus. I haven't been watered since March and honestly, I'm thriving on neglect and spite.

109 characters. One line. A cactus with a voice: unwatered since March,
unbothered, and thriving on neglect and spite — the punch lands at the end.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library, makes no network calls,
and needs no API key. It writes exactly one line to `/output/entry.txt`.

## How the line was picked

Six candidate lines were drafted, then judged pairwise against the kit's
judge brief (plant voice first, fresh surprise, plant life driving the joke,
tightness, originality) using the Caffeine inference router. The cactus line
won all three of its pairings (margins 3, 2, 3) and was picked on that
judging, not on gut feel.

| Pairing | Result |
|---|---|
| #1 fern-union vs #2 fern-pile | #1 won, margin 3 |
| #3 monstera vs #4 cactus | #4 won, margin 3 |
| #5 fern-queue vs #6 dead plant | #5 won, margin 3 |
| #1 fern-union vs #4 cactus | #4 won, margin 2 |
| #4 cactus vs #5 fern-queue | #4 won, margin 3 |

6. "The houseplant is out of office. It died in March. This auto-reply is the only thing still alive in this flat." (110)
